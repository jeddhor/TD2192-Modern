## State of the C-0010 test

See the final report and the commit messages for the last result.

The method:
- Dumps every 35 frames are compared with the state after the tick, allowing a dump taken mid-tick (logic of t, HUD of t − 1, or all of t − 1).
- The chord holds are mapped from frames to ticks by interpolating the dump tick counters. Each hold start is fitted ±3 ticks so that it matches this dump and the next one.

Pitfalls:
- **I/O:** the oracle reads are I/O-bound and slow when other agents load the drive (minutes).
- **U-160:** ships fire on two-digit headings. The original then reads DGROUP DS:04F6..10A6, which the test takes from C-0009's first dump (constant over C-0009's flight). With (0, 0) instead, slot 19 died at tick 1187 in ours and not in the original.
