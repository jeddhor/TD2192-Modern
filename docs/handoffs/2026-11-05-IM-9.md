## Gotchas

- **C-0041 sampling.**
  - The physics globals are set after the tick wait: view, armour, shields, speeds, and mission over. Read them from the first frame of tick t + 1.
  - Ships and mission globals: read them from the last full frame of tick t, and only when the capture continues into tick t + 1.
  - Between the full-dump ranges the counter is dumped every second frame. So the key change at frame 1458 is ambiguous for tick 107; the test keeps the key state whose speeds match.
- **Line endings.** Python edits on Windows write CRLF unless you open the file with `newline=''`.
