## Notes

- Episode 3 ships `m1.td3`..`m19.td3` plus `m21.td3` (no `m20.td3`). Episodes 1 and 2 ship `m1`..`m20`. See UNKNOWNS.md U-012.
- `tdstatus.dat` is referenced by td1.exe and file0001.exe but is **not** shipped; it is created at runtime (inter-process state). See UNKNOWNS.md U-004.
- `helihangar.scr` in the executables resolves to `helihang.scr` because DOS truncates base names to 8 characters. The port's asset locator must apply 8.3 truncation and case-insensitive matching.
- `c:\dos\label.exe` and the string `PLAY TD2192` appear in file0001.exe. This looks like a prank/anti-cheat path that modifies the host disk label. Document it; **never** reproduce it.
