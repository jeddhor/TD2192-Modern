# TD2192-Modern 0.9.1 beta

This is the first public beta of the modern port. It includes all three episodes,
the faithful Classic profile, optional Enhanced features, controller support, and
the Qt6 offline installers for Windows and Linux. The owner signed off the M12
audio and Enhanced review. Classic parity passes 363 of 376 checklist items
(96.5%).

## Install

Download the `windows-x64-setup.exe` or `linux-x64-setup.run` file for your
platform. On Linux, make the `.run` file executable before launching it. The
installer copies the precompiled game and its dependencies into your user folder
by default. Point it at your own retail copy of *Traffic Department 2192* to
import the required data. It can create application menu and desktop shortcuts
and includes an uninstaller. No original game content is distributed here.

Keep the matching `setup-source.zip` alongside each installer. It contains the
installer source, rebuild instructions, and dependency notices. The two portable
game archives are available for manual installation. `SHA256SUMS` covers every
download in this release.
